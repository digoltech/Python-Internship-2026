## Task 5 — Type Casting Practice

The following values are received as strings, exactly as they would come from a form on a website. Convert them to the correct type and perform the requested operation.

```python
height_cm = "175"

```

Write a program that converts both values to the correct numeric type, then calculates and prints BMI using the formula below:

```
BMI = weight_kg / (height_m * height_m)
```

Note: height_cm must be converted to meters first by dividing by 100.
