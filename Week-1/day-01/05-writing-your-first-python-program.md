# Writing Your First Python Program

## Creating Your First File

1. Open VS Code
2. Create a new file and name it `hello.py`
3. The `.py` extension tells VS Code and your computer that this is a Python file

## The print Function

The `print` function displays text or values on the screen. It is the most basic way to see output from your program.

```python
print("Hello, World!")
```

Run this file. You will see the following output in the terminal:

```
Hello, World!
```

## How It Works

`print` — This is a built-in Python function. A function is a named block of code that performs a specific task.

`( )` — The parentheses hold the input you are giving to the function.

`"Hello, World!"` — This is a string. Any text wrapped in quotation marks is treated as a string — plain text data.

## Printing Multiple Lines

Each `print` call outputs on its own line.

```python
print("Hello, World!")
print("I am learning Python.")
print("This is my first program.")
```

Output:

```
Hello, World!
I am learning Python.
This is my first program.
```

## Printing Numbers

You can also print numbers directly without quotation marks.

```python
print(100)
print(3.14)
```

Output:

```
100
3.14
```

## Printing Text and Numbers Together

```python
print("My age is", 21)
```

Output:

```
My age is 21
```

When you separate values with a comma inside `print`, Python automatically adds a space between them.

## Real-Life Connection

Every application you use — whether it is a bank app, a navigation tool, or a shopping website — has output. Output is how a program communicates back to the user. `print` is your first tool for creating output.
