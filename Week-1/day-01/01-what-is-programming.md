# What is Programming

## Definition

Programming is the process of giving a computer a set of step-by-step instructions to solve a problem or complete a task.

A computer does exactly what you tell it to do — nothing more, nothing less. Your job as a programmer is to write those instructions clearly and in the right order.

## Real-Life Analogy

Think about making tea. You already know the steps without thinking:

1. Boil water
2. Add tea leaves
3. Add milk
4. Add sugar
5. Strain and pour into a cup

This is called an **algorithm** — a step-by-step process to solve a problem. Programming is writing algorithms that a computer can understand and execute.

## What is a Programming Language

A computer does not understand English or Hindi. It understands only binary — 0s and 1s.

A programming language acts as a bridge between human language and machine language. You write instructions in a programming language, and the computer translates them into binary to execute.

Examples of programming languages: Python, JavaScript, Java, C++

## Key Terms

**Algorithm** — A step-by-step set of instructions to solve a problem.

**Program** — An algorithm written in a language the computer can understand.

**Code** — The actual text you write using a programming language.

**Syntax** — The rules of a programming language. Just like grammar rules in English, syntax rules must be followed for the computer to understand your instructions.
